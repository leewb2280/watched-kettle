# Mori Bot

프로젝트를 위해 2026-09-14에 제작한 오리지널 로봇 펫입니다. 아이보리 몸체, 남색 화면, 청록색 화면 눈을 사용합니다.
기존 캐릭터 이미지나 로고를 참조 자료로 사용하지 않았습니다. AI 이미지 생성 후 프레임 추출·등록·투명도 정리·V2 조립을 수행했습니다.

- 검수: 구조·투명도 검사 통과, 3인 독립 방향 검수의 기본 4방향 통과. 일부 중간 각도의 시선 변화와 걸음은 단순한 로봇 동작으로 유지했습니다.
