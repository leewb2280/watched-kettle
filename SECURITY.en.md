# Security and privacy

[한국어](SECURITY.md) · [English](SECURITY.en.md)

Do not attach original conversations or databases containing your work, tokens or sign-in information to public issues.
When reporting a problem, include the app version, the Windows version, the steps to reproduce and a diagnostic summary with personal information removed.
Report security issues through this repository's **Security → Report a vulnerability** (GitHub private vulnerability reporting) instead of a public issue.
Reports are visible only to the repository maintainers. Include the steps to reproduce and the scope of impact, and you will receive a reply after review.

Permission to read conversations and permission to run tasks are kept separate. No new task is sent while encryption has failed, the account is unknown, the connection is broken or execution ownership is unclear.
DPAPI data depends on the current Windows user and computer, so a review queue copied to another PC is not guaranteed to be recovered automatically.
Instructions that cannot be recovered are reviewed again in the original conversation and registered again. Items with unclear execution results are not resent until confirmed.
