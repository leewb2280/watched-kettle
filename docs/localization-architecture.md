# 언어팩 구조와 책임

## 경계

| 계층 | 책임·입출력·상태·부수효과·수명 |
|---|---|
| `localization/catalog.py` | Qt 독립 문구·변수 검증과 표시 함수. 기준 카탈로그는 지연 읽기·캐시하고 번역기는 한 실행의 불변 사전이다. 상태 판정·설정 저장을 하지 않는다. |
| `localization/collections.py` | 모듈 수준의 레이블 표를 사용 시 해석한다. 모듈 import에서 언어를 확정하거나 파일을 읽지 않는다. |
| `localization/packs.py` | 한 단계 폴더 발견·검증·중복 판정·선택 가능 목록과 사용자 팩의 보완 팩 결정. 활성 사전과 재검색 목록을 구분한다. 조회가 활성 언어를 교체하지 않는다. 항목별 문제는 키와 사유 코드만 남긴다. |
| `localization/editing.py` | 편집용 복사본과 `reference.json` 생성(설정창과 번역자 도구가 공유). 점 폴더에 쓴 뒤 새 이름으로 바꾸며 기존 폴더를 덮어쓰지 않는다. 선택 저장은 하지 않는다. |
| `application/localization.py` | 사용자 경로·저장 선택·설치 언어를 연결하고 시작 복구 전에 활성 언어를 설정한다. 상태줄용 작은 표시 사전을 원자적으로 저장한다. |
| 공통 설정 어댑터 | 명령 검증·설정 저장·revision·변경 신호를 소유한다. 언어 목록 조회는 저장하지 않는다. `language.copy`는 복사 뒤 기존 언어 선택 저장 경로를 거치고, 새 팩 ID와 목록만 응답한다(경로 비노출). |
| 설정 host / Electron | 기존 인증·노출 목록·4MiB 제한으로 사전을 전달한다. 초기 사전과 폴더 열기는 main 전용이며 renderer 경로를 수용하지 않는다. |
| 앱 재시작 | `app.py`가 정상 종료·runtime 정리·단일 인스턴스 해제 후 재실행한다. `application/restart.py`는 중복 요청을 막고 같은 구성과 인수를 보존한다. host의 `app.restart`는 실행 경로나 인수를 받지 않는다. |
| React / QML | 받은 사전 또는 Python 표시값을 사용한다. App의 snapshot·명령 큐, 기존 기능별 훅·초안·ACK 수명은 유지한다. |
| Claude Code 상태줄 | 앱이 저장한 네 개의 표시 템플릿만 제한하여 읽는다. Qt·Babel·전체 언어팩 로더를 import하지 않는다. |

기본값은 저장된 팩, 설치 언어의 공식 팩, 공식 한국어 순서다. 사용자 팩의 빠지거나
잘못된 항목은 같은 기본 언어 코드의 공식 팩, 그 밖에는 공식 영어, 마지막으로 카탈로그
한국어로 채운다. 이 병합은 앱 실행 목록(`LanguagePacks`)에서만 하며, 단독 검사
(`load_pack`, 번역자 도구 `check`)는 팩 자체 문구만 본다. 런타임 언어 전환은
지원하지 않는다. 설정창 프로세스를 다시 실행해도 부모 앱의 활성 사전을 받는다.
모듈 상수에 표시 언어를 고정하지 않으며, 레이블 표와 데이터 모델 기본값은 실제
사용·인스턴스 생성 시 해석한다.

저장한 선택과 활성 언어가 다르면 언어 카드의 버튼 줄(폴더 열기·다시 읽기·복사) 오른쪽 끝에 `앱 다시 시작` 버튼을 표시한다.
기존 언어 제목·설명·선택창 행은 이동하지 않으며 활성 언어를 다시 고르면 버튼을 숨긴다.
저장·재검색·복사·재시작 중에는 중복 조작을 막고, host는 업데이트 적용·다운로드 또는
펫 일괄 작업 중 재시작을 거부한다. App의 기존 명령 큐를 사용하며 재시작 응답 뒤에는
종료 중인 host에 snapshot을 다시 요청하지 않는다. 정적 적용 설명은 유지하고 중복된
`language.pending`은 폐기했다. 복사 완료 안내는 편집 방법만 설명하고 복구 경고는 별도로 표시한다.

재시작은 저장된 언어를 읽고 앱 설정 페이지를 다시 연다. 소스 실행은 같은 구성의
절대 진입 스크립트와 기존 작업 경로·펫 인수를 유지한다. 설치판은 같은 실행 파일을
재실행하며 [PyInstaller 재실행 지침](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html)에
따라 독립 프로세스 환경을 지정한다. 설치기와 installer revision은 변경하지 않는다.
실행 실패 시 저장한 선택을 유지하고 번역된 오류와 진단 이벤트를 남긴다.

## 문구와 상태

문구 ID와 변수·문맥·revision의 기준은
`watched_kettle/localization/resources/catalog.json`이다. 기존 ID는 표현 변경 시에도
유지하고, 의미·변수 변경 때 revision을 올린다. 공식 영어 원본도 같은 키를 사용한다.
상태·오류·출처·그룹 ID와 저장 키는 번역하지 않는다.
기본 대화 제목과 같은 실제 사용자 제목도 유효하다. 이름 확인은 제목의 존재로만 판단한다.
업데이트 안내의 종류도 표시 문구를 비교하지 않고 서비스 내부 상태로 구분한다.

컨트롤의 `groupId`는 고정 분류이며 기존 `group`은 표시용 레이블이다.
메타데이터의 빈 제목은 미확정 상태이고 실제 제목은 원문으로 보존한다. 기본 대화
제목은 화면 행을 만들 때만 붙인다. 말풍선 요약·초과 안내는 상태가 포함된 조각으로
전달하고 표시 문장을 다시 해석해 정렬·강조·버튼을 고르지 않는다.

상태 수집·서비스 소유권과 시간·중복·계정·감시 세대·클릭 토큰은 바꾸지 않는다.
[말풍선 기준](bubble-architecture.md)의 BA-01·BA-05·BA-06·BA-09·BA-10을 보존한다.
동결된 후보 분석·대기열·자동 실행은 이 이전에 포함하지 않는다.

## 검사와 범위

팩당 manifest 16KiB, 메시지 1MiB, 사용자 폴더 최대 128개를 읽으며 파일 연결은 따르지
않는다. 중복 JSON 키, 지원하지 않는 형식·언어·방향과 잘못된 변수는 검증한다.
사용자 팩 오류에 원본 경로·JSON·파서 세부정보를 노출하지 않는다.
문구는 평문으로 렌더링하고 기존 rich text의 강조는 앱이 제어한다.
유효하지 않은 유니코드 스칼라와 C0/C1 제어 문자는 거부한다(본문의 줄바꿈·탭 제외).
구체적인 BCP 47 언어 코드 중 Babel과 고정 Electron의 복수형·수·날짜 API가 함께 지원하는
목록만 허용한다. 목록은 `scripts.generate_language_locales`로 생성하고 UI 패키징 시
실제 두 의존성으로 최신성을 검사한다. `root`, `und`, ICU modifier는 받지 않는다.

재시작 회귀 검사는 중복 요청·구성·인수·실패·작업 중 거부를 확인하며, 별도 Qt 프로세스가
기존 인스턴스 해제 뒤 저장된 언어를 읽는지도 확인한다. 영어 화면 QA는 선택창의 위치와
버튼의 아래 배치·표시·숨김·요청 1회를 검사한다. 화면 QA의 재시작 콜백은 기록용 대역이므로
설치판 전체 재실행 검수와 구분한다.
상태줄 사전의 한 문구 상한은 일반 팩과 같은 16,384자이며 읽기 바이트 상한은
네 문구의 최대 UTF-8 크기와 JSON 여유분이다. 손상된 형식은 기본 문구로 보완한다.

`scripts.language_pack`은 템플릿·비교·검증을 제공한다. 설치판 사용자는 설정창의
편집용 복사로 같은 형식의 팩과 `reference.json`을 얻는다. 복사본은 원본 팩 자체 항목의
revision을 유지하고, 다른 언어의 공식 팩으로 보완되던 항목은 빈 값으로 남긴다.
필수 검사에는 공식 영어 완전성, Python/JavaScript 복수형, 설정 계약과 두 설치 구성
타입·빌드·경계 검사가 포함된다. 긴 번역·배율·설정 초안·계정 변경·상태줄 폭은 실제
화면 QA로 확인한다. 공개 반영과 배포는 개발 저장소의 릴리스 절차에 따른 두 승인을 별도로 거친다.

### 누락 방지 검사

영어와 한국어가 어긋나는 경로를 `scripts.localization_guard check`(필수 검사의 `Localization guards`)와
`settings-ui/scripts/localization-literals.test.cjs`가 막는다.

- **하드코딩 한글**: `watched_kettle/`의 Python 문자열(docstring 제외)과 QML/JS 문자열에 한글이 있으면
  실패한다. 설정창(`settings-ui/src`, `settings-ui/electron`, `localization.cjs`)은 TypeScript 파서로
  문자열·템플릿·JSX 텍스트를 같은 기준으로 검사한다. 화면에 나가지 않는 예외(동결된 작업 기능, 내부 오류,
  상태줄 기본 문구, 설정 연결 전 긴급 문구)는 `scripts/localization_literals.json`의 `korean`에 파일별 개수와
  이유로 기록한다. 개수가 늘어도 줄어도 실패하므로 목록은 실제와 같게 유지된다.
- **하드코딩 영어**: 설정창 JSX 텍스트와 `title`·`placeholder`·`aria-label`·`alt`·`label` 속성에 영어 단어를
  직접 쓰면 한국어 화면에도 그대로 나오므로 실패한다. 제품명·명령·단위처럼 번역하지 않는 문구만 같은 파일의
  `untranslated`에 이유와 함께 두며, 더 이상 쓰지 않는 항목도 실패한다.
- **없는 키**: `t()`·`MessageId()`·`parts()`·`<LocalizedText id>`로 쓴 키가 catalog에 없으면 사용 위치와 함께
  실패한다. 없는 키는 화면에 키 이름이 그대로 보인다. 접두어를 이어 붙이는 동적 키는 대상이 아니다.
- **원문만 바뀐 경우**: `scripts/localization_source.lock.json`은 키마다 revision과 원문(`value`·`variables`·`plural`)
  해시를 기록한다. 같은 revision에서 원문이 바뀌면 실패한다. 뜻이 바뀌었으면 revision을 올리고(공식 영어팩
  검사가 `sourceRevision` 불일치로 영어 갱신을 요구한다) `lock`으로 잠금을 갱신한다. 뜻이 같은 표현 수정만
  `lock --wording-only KEY`로 반영한다. `lock`은 검토하지 않은 원문 변경을 거부한다.

### 영어 화면 QA

`check.ps1 -LanguageQa`(CI의 품질 검사, `-Full`도 포함)는 두 설치 구성의 설정 UI를 빌드할 때마다
`settings-ui/scripts/language-qa.cjs <구성> en`을 실행하고 결과를 `dev-artifacts/language-qa/check-<시각>/`에 남긴다.
CI에서 실패하면 같은 폴더를 `language-qa` 산출물로 올린다.

- 모든 탭과 펫 관리·말풍선 꾸미기 대화상자에서 한 글자라도 남은 한글, 풀리지 않은 메시지 ID, 상자보다 넓어
  잘리거나 넘치는 앱 문구를 찾는다. 150%·200% 확대와 좁은 창의 가로 넘침도 확인한다.
- pet-assistant는 Codex 한도와 Claude Code 대화·한도를 채운 뒤 데이터가 있는 화면과 사용량 기록 목록,
  대화 상세 대화상자를 다시 확인한다.
- 사용자 값(프로젝트 이름, 대화 제목 등)은 그대로 보존하는 텍스트라 검사에서 뺀다. 화면 코드는 실제 값을
  `data-user-text` 요소로 감싸고, 값이 없을 때의 대체 문구는 감싸지 않아 계속 검사되게 한다. 사용자 값 때문에
  줄인 행은 잘림 검사에서도 뺀다. 언어 이름 `option`도 같은 이유로 제외한다.
- 매 실행 시작 시 실제 렌더러에 시험 요소를 넣어 검사기가 한 글자 한글과 잘린 문구를 잡는지 먼저 확인한다.

트레이 메뉴와 프로젝트 카드 문구의 영어 결과는 `tests/test_localization_guards.py`가 확인한다. 말풍선 창,
Windows 알림, 상태줄 폭처럼 Qt·외부 화면의 실제 배치는 이 QA 범위 밖이며 실제 화면 검수로 확인한다.

[언어팩 제작·설치 안내](language-packs.md)를 함께 유지한다.

## 복수형 호환 목록

지원 여부뿐 아니라 고정 Electron과 Babel의 복수형 결과도 생성 시 대조한다.
0~200의 정수, 나머지·백만 경계, 소수·음수를 포함하는 회귀 수치 집합을 사용한다.
이는 모든 실수에 대한 수학적 증명이 아니라 의존성 변경 시 되풀이하는 호환 검사다.
불일치 코드는 locales.json의 excludedPluralLocales에 기록하고 앱 선택에서 제외한다.
현재 kok 계열과 일부 pt 지역 코드는 두 엔진의 규칙·지역 fallback 차이로 제외된다.
호스트 Node의 언어 지원 범위를 기준으로 제품 언어를 줄이지 않는다.
검사는 scripts.generate_language_locales --check 및 전체 회귀에서 실행한다.

제거한 ID는 retiredIds에 보존한다. 새 문구에 이 ID를 재사용하지 않는다.
