# 펫의 자동·수동 외형 전환

## 범위와 책임

외형은 펫의 작업 상태와 독립된 표시 상태다. 현재 펫 안에서 동작·시선 프레임 집합을
교체하며, 전환 때문에 펫을 다시 선택하거나 활동 이벤트를 생성하지 않는다.
BA-01·BA-06·BA-07·BA-10과 [유지보수 경계](maintenance-boundaries.md)를 보존한다.

| 경계 | 입력·출력·상태·부수효과·수명 |
|---|---|
| 자산 검증 | `appearance_assets`가 선택적 매니페스트와 이미지 규격을 검증한다. Qt·사용자 설정·작업 상태를 소유하지 않는다. 로더·가져오기·빌드가 같은 선언을 사용한다. |
| 외형 전환 | `AppearanceController`가 모드·확정 외형·목표·자동 대기·안전 대기·전환 프레임과 타이머를 소유한다. `AppearanceTransitions`가 쌍마다 그린 전환, 반대 방향의 역재생, 정면 대기 프레임 겹치기 중 하나를 고른다. 설정 저장·화면 갱신·확정 외형 적용은 전달받은 콜백으로 실행한다. 펫 교체·종료 시 정리한다. |
| 펫 창 | 실제 안전 조건과 프레임 집합·그리기를 담당한다. 외형 변경은 작업 애니메이션 상태, 말풍선 테마·수명·위치를 초기화하지 않는다. |
| 설정·메뉴 | ViewModel과 기존 설정 큐·명령 경로로 외형 선택을 전달하고 실제/대기 상태를 표시한다. React에 별도 전환 상태나 타이머를 만들지 않는다. |

## 동작 정책

- 모드는 `auto` 또는 패키지가 선언한 외형 ID다. 새 펫은 자동·기본 외형으로 시작한다.
- 자동은 확정 후 정한 간격의 무작위 시각에 다른 외형을 요청한다. 간격은 펫별 선택(10~30초,
  1~3분, 3~10분, 10~30분, 30~60분) 또는 패키지 `auto` 값이고 없으면 60~180초다. 다음 외형은
  지금 모습을 뺀 무작위 또는 선언 순서이며, 순서 선택은 외형이 셋 이상일 때만 보인다.
  간격을 바꾸면 기다리던 자동 전환을 새 간격으로 다시 잡는다. 전환할 수 없으면
  한 건만 보류한다. 수동 선택은 즉시 저장하고 자동을 끈다. 현재 모습의 유지 선택도 동일하다.
- 그린 전환이 없는 쌍은 반대 방향 전환을 거꾸로 재생하고, 그것도 없으면 두 외형의 정면 대기
  첫 프레임을 8프레임(50ms) 동안 겹친다. 겹친 프레임은 지금 쌍 하나만 기억한다.
- 펫이 보이고 정면 idle이며, 실제 작업 상태도 idle이고 드래그·시선 추적·자동 이동·
  자동 행동이 없는 상태를 300ms 유지한 뒤 재생한다. 대기 중 새 자동 행동·이동을 시작하지 않는다.
- 전환 중 작업 동작·마우스 접근·드래그가 시작되면 원래 확정 모습으로 즉시 복귀한다.
  수동 목표는 다음 안전 시점까지 남기고 자동 목표는 버려 새 간격으로 예약한다.
- 연속 선택은 마지막 목표 하나만 유지한다. 자동으로 돌아가면 수동 대기를 지운다.
- 전환 중간 프레임은 저장하지 않는다. 펫별 모드·마지막 확정 외형·자동 간격·순서를 저장한다.
  재시작 시 자동은 마지막 확정 모습, 수동은 지정 모습으로 바로 시작한다.
- 숨김은 진행 중 전환과 타이머를 취소한다. 다시 보이면 자동은 새 간격으로 시작하고,
  수동 목표는 안전 조건을 다시 기다린다. 펫 교체·종료 시 이전 타이머와 요청을 폐기한다.

## 인터페이스

설정의 펫 → 동작과 우클릭 메뉴에서 자동/각 외형 유지를 고른다. 설정에는 자동 전환 간격과
(외형이 셋 이상이면) 순서도 있으며 자동이 아닐 때는 비활성이다. 지원하지 않는 펫에는
항목을 표시하지 않는다. 공통 문구는 카탈로그와 공식 영어 팩, 외형 이름은 패키지의
언어별 labels를 사용한다. 실제 외형·전환 중·전환 대기를 선택 모드와 구분한다.
머리 모습의 현재 상태와 전환 설명은 제목 옆 정보 아이콘에 모아 마우스 올림·키보드 초점으로
확인한다. 선택은 기존 네이티브 select를 유지하고 공통 버튼 색·테두리·둥근 모서리와 여백을
사용한다. 이 표시 방식은 React의 해당 행에만 적용하며 외형 상태·명령·타이머를 바꾸지 않는다.

설정창 테마에 이미 `appearance` 키가 있어 새 컨트롤 키는 **`pet_appearance`**다.
기존 `settings.set` 명령과 version 1을 유지하며 간격·순서는 `pet_appearance_interval`·
`pet_appearance_order` 키다. snapshot의 선택적 `appearance`에는
`mode/current_id/target_id/transitioning/pending/choices/interval/order/package_auto`를 전달한다.
전환 프레임마다 snapshot을 보내지 않고 선택·대기·시작·완료·취소 때만 갱신한다.

`pet.preview`와 `pet.import.preview`는 선택적 `appearanceId`를 받는다. 기존 요청은 그대로
사용할 수 있다. 설정·홈의 현재 펫 이미지는 확정 외형을 조회하며 캐시·요청 세대에 외형을
반영한다. 가져오기 프레임 미리보기는 외형별 9동작·16방향을 제공하고 한 번에 8셀 상한을 유지한다.

패키지 선언·검증·구버전의 기본 모습 표시 방식은 [펫 패키지 규격](pet-package-format.md)을 따른다.
추가 이미지는 로컬·ZIP 가져오기, 내용 식별자, 비공개 자산 복사와 Windows 빌드에 포함한다.
원본·실패 후보·프롬프트·중간 결과·상세 QA는 내부 `pet-workspaces/README.md`의 작업공간 규칙에 따라
비공개 동반 저장소에 보존한다. 기존 펫 패키지는 덮어쓰지 않는다.

## 펫 잇기

설정의 펫 → 외형·표시 → **펫 잇기**에서 설치된 V2 펫(1536×2288) 2~6개를 한 펫의 모습으로 묶는다.
원래 펫은 바꾸지 않고, 결과는 `appearanceSet` 버전 2 패키지로 펫 가져오기와 같은 준비·등록 경로
(`PetImporter.prepare_bytes` → 등록)를 거쳐 사용자 펫 폴더에 새 펫으로 생긴다(`importSource: "link"`).
같은 내용이면 같은 ID가 되며, 휴지통에 같은 펫이 있으면 복원을 권한다.

| 경계 | 입력·출력·상태·부수효과·수명 |
|---|---|
| `pet/linker.py` | Qt 없이 전환 이미지를 192×208 칸 줄 이미지로 정규화하고 묶음 패키지의 선언·자산을 만든다. 설치 경로를 기록하지 않는다. |
| `PetLinkSession` | 설정창에서 고른 전환 이미지를 쌍(펫 ID)별로 들고 있다가 만들기·창 닫기·초기화 때 버린다. 미리보기는 축소 PNG로만 보낸다. |
| 설정창 | 고르기 → 전환 넣기 → 확인 단계를 보여 준다. 파일 경로는 Electron 주 프로세스만 다루고(`file.link.transition`), 화면 코드는 경로를 보지 않는다. |

- 모습 이름은 각 펫 표시 이름으로 시작하고 고칠 수 있다. 첫 기본 모습의 표시 크기·시선·자동 행동
  설정을 이어받고, 말풍선은 고른 모습의 디자인과 장식 이미지만 복사한다.
- 전환 이미지는 칸을 가로로 이어 붙인 PNG·WebP, 움직이는 GIF·WebP, 이름 순서의 여러 PNG다.
  2~48프레임, 프레임마다 투명 배경이 필요하다. 칸 크기가 다르면 비율을 지켜 줄이고 바닥에 맞춘다.
  움직이는 이미지는 평균 프레임 시간을 쓰고 사용자가 16~1000ms로 바꿀 수 있다.
- 전환을 넣지 않은 쌍은 반대 방향을 거꾸로 재생하거나 겹쳐 바꾸며, 미리보기도 같은 규칙을 따른다.
- 자동 간격·순서는 만들 때 패키지 `auto`로 저장되고, 이후 펫별 설정으로 바꿀 수 있다.
- **묶음 펫 고치기**: 잇기로 만든 펫(`importSource: "link"`)을 다시 열면 모습은 `<펫 ID>#<모습 ID>`로,
  그린 전환은 그대로 불러온다. 이름·순서·기본 모습·전환·말풍선·자동 설정을 고치고 다른 펫을 더할 수 있다.
  저장하면 새 내용의 펫을 등록한 뒤 이전 펫의 설정(모습 모드와 현재 모습은 위치가 바뀔 수 있어 제외)과
  목록 위치를 옮기고, 이전 펫이 현재 펫이면 새 펫으로 바꾼 다음 이전 펫을 휴지통으로 보낸다.

## 검증

`test_pet_appearance`는 자동 간격·안전 대기·수동 고정·마지막 선택·중단·숨김·재시작,
기존 로더 계약, 폴더/ZIP 식별자·자산 보존, 잘못된 경로·추가 이미지와 메뉴 명령을 검사한다.
설정 프로토콜·브리지·가져오기·빌드 수집·말풍선 안정성 회귀와 두 구성의 한영 화면을 확인한다.
필수 검사 진입점은 `scripts/check.ps1 -LanguageQa`다. 실제 실행 결과와 자산 품질 한계는
변경 완료 기록과 새 펫 README에 남긴다. 공개 동기화·푸시·설치기·Release는 별도 배포 절차다.
