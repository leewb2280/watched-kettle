# Watched Kettle 0.15.11

[한국어](v0.15.11.md) · [English](v0.15.11.en.md)

This version adds an editor for designing speech bubbles yourself and Join pets, which combines several pets into the looks of one pet. It also includes improvements following a full review of security, stability and performance.

**You only need `WatchedKettle-0.15.11-public-unsigned-setup.exe`.**

> This is an unofficial project. It is not made or endorsed by OpenAI or Anthropic and has no affiliation with either company.

## Installer correction republished on 2026-11-01

- Fixed an in-app update sequence that restarted the old app before replacing its runtime, causing installation to fail. The app now restarts only after the runtime replacement and subsequent setup have completed.
- A failed replacement keeps the previous runtime and does not restart the app. Setup also distinguishes a successful installation followed by a failure to start the app.
- The initial 0.15.11 release was withdrawn and its installer was corrected under the same version at the user's request. **An installation of the initial 0.15.11 cannot automatically detect a corrected release with the same version. Run the new full installer manually to reinstall it.** Versions 0.15.10 and earlier can use in-app updates.

## Install and update

- **New install:** Download `WatchedKettle-0.15.11-public-unsigned-setup.exe` and its `.exe.sha256` from the Release. Compare the hash with `Get-FileHash .\WatchedKettle-0.15.11-public-unsigned-setup.exe` in PowerShell, then run it.
- **Updating from 0.15.10 or earlier:** The installer itself changed in this version, so instead of downloading only the changed files, the app downloads the update installer for your setup once. Use `App settings → Version & updates → Check for updates → Update`.
  In this case the automatic install in 0.15.10 does not download the large installer by itself; it only tells you about the new version.
- **Updating from 0.15.4 or 0.15.3:** The same steps download the full installer.
- Your chosen setup, tools, settings, your own pets and history are kept. The history database format is unchanged. The installer is unsigned, so Windows SmartScreen may warn you.

## Bubble design

- `Customize → Edit bubble design` is now an editor with sections: **background** (solid color, patterns, your images), **border**, **shape** (corners, tail, inner line, glow, text padding) and **decorations**.
- Click a decoration in the preview to select it, drag it to move it and resize it. You can stack built-in decorations and your own images in layers.
- Add your images by drag and drop or paste, and reuse them from a collapsible thumbnail library. Adding the same picture again does not create copies.
- Save a design under a name, share it as a file with another PC, or export it for a pet package.
- Stacked bubbles with large decorations no longer leave overly wide gaps between them.
- The bubble editor opens directly as a spacious workspace. Open and fold editing panels from the tabs on the right, fit the preview or zoom up to 400%, and pan with Space+drag or the middle button. Zoom and pan do not change the saved design.

## Join pets and look changes

- `Join pets` combines installed pets into several looks of one pet. You can add transition animations between the looks and reopen a joined pet to edit it.
- Look changes in pet packages now support more than two looks and optional transitions. See [Pet appearance](../pet-appearance.md) for the format.

## Pet and settings window

- Set the pet animation speed from 50% to 200% under `Customize → Pet`. It applies to all pets.
- Switches and buttons in Manage pets no longer ignore a click right after another change.
- Slider values no longer get cut off next to a long description in the settings window.
- The pet import window is organized into input, review and result steps.

## Security and stability

- The settings window now runs on Electron 44.9.3, which includes security fixes. Its executable is locked so other programs cannot use it as Node or attach a debugger.
- The app and its integrations no longer look up external programs (Git Bash, PowerShell, Codex and others) by name alone; they run them only from known locations. A file with the same name in the project you are working in is never run.
- On a PC shared by several Windows users, the second user's app could fail to start. The connections between the app and its integrations are now separate for each user.
- After an update has been downloaded, installing a newer version yourself no longer brings back the older version on the next start. The installer checks the new version before swapping it in; if you cancel or the install fails, the existing version stays. Files only an earlier version had no longer remain in the install folder.
- Backups made when Codex or Claude Code settings change are limited to the newest 5 per file. Backups left by earlier versions are trimmed when you install or update.
- Very large pictures are refused as bubble images, and bubble design files are checked more strictly.

## Performance

- The integration that runs every time Codex or Claude Code uses a tool finishes faster (measured p95 104 → 85 ms on the development PC).
- While nothing is happening, the app spends less CPU checking Codex logs and the account, and keeps fewer background processes.

## For pet package creators

- Look changes v2 (several looks, optional transitions) and bubble decoration layers are available. See the [pet package format](../pet-package-format.en.md) and [Pet appearance](../pet-appearance.md).
- Decorations made in the bubble editor can go into a package with `Export for a pet package`.
