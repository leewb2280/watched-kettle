# Watched Kettle 0.15.5

2026-10-17 공개. Codex·Claude Code 활동 표시의 정확도, 워크트리 세션의 프로젝트 묶기, 풀린 도구 연결 알림, Claude Code 한도 연결, 설정창 아이콘, 업데이트 파일 위치 변경을 담았습니다.

**`WatchedKettle-0.15.5-public-unsigned-setup.exe` 하나만 받으면 됩니다.** 나머지 첨부는 0.15.4 앱이 업데이트할 때 자동으로 사용합니다.

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.5-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.5-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.4에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 바뀐 파일만 받으며, 이번에는 실행 환경(Python 3.14) 교체로 구성마다 약 120MiB를 받습니다.
- **0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## Codex 활동 표시

- 로그에서 작업이 끝났다는 신호만 읽힌 경우 `완료`가 아니라 `종료됨`으로 표시합니다. 같은 작업의 Codex hook이나 Codex App Server 조회(읽기 전용)로 끝난 것이 확인될 때만 완료로 기록합니다.
- 제한 때문에 멈춘 작업은 `사용량 제한으로 중단`, `요청 제한으로 중단`, `예산 제한으로 중단`, `컨텍스트 제한으로 중단`으로 사유를 표시합니다. 오류 원문은 저장하지 않습니다.
- 최근 활동을 받지 못해 끝났는지 확인되지 않은 작업은 툴팁에 마지막 확인 시각을 보여 주며, ×를 눌러 숨길 수 있습니다. 확인되지 않거나 내부용인 세션은 펫의 작업 중 표시에 넣지 않습니다.
- Codex 계정을 바꾼 뒤 이전 계정의 활동이 다시 나타나지 않습니다.

## Claude Code 활동 표시

- 작업과 작업 사이에 `/compact`를 직접 실행한 뒤 펫이 10분 동안 작업 중으로 남던 문제를 고쳤습니다.
- 10분 넘게 일한 하위 에이전트가 끝난 뒤 완료가 표시되지 않던 문제를 고쳤습니다. 끝나지 않은 도구가 있는 동안에는 긴 확인 대기 시간을 씁니다.
- Claude Code가 확인을 기다리는 상태는 `권한 요청`으로 표시합니다. 승인한 뒤에도 그 도구가 끝날 때까지 남을 수 있다는 툴팁을 붙였습니다.
- 워크트리나 하위 폴더에서 연 Claude Code 세션도 주 저장소 이름의 카드 하나로 보이고, 사용량 기록의 프로젝트도 합쳐집니다. 이전에 저장된 워크트리 기록은 따로 남습니다.

## 도구 연결

- 설치기나 `연결·진단`에서 Claude Code를 켜면 `한도 가져오기`도 함께 켜집니다. 한도만 따로 끌 수 있습니다.
- 작업 상태 연결과 한도 연결이 모두 켜진 상태에서 Claude Code를 끌 때, 한도 연결을 되돌리지 못하고 스위치가 켜진 채 남던 문제를 고쳤습니다.
- 켜 둔 Codex·Claude Code의 연결(hook)이 지워지거나 바뀌면 펫 말풍선으로 다시 연결하라고 알립니다. 앱을 실행할 때마다 한 번 알리고, 누르면 `연결·진단`이 열립니다. 트레이 메뉴와 설정 홈에도 표시합니다.
- 앱을 설치한 뒤 새로 설치한 도구는 한 번 연결을 권합니다.

## 설정창

- 설정창에서 다른 페이지로 옮겨 갔다 돌아와도 편집 중인 내용·필터·선택이 유지됩니다. 저장·충돌 처리와 알림 확인 절차는 그대로입니다.
- 설정창의 작업 표시줄·창 아이콘이 Electron 로고 대신 앱 아이콘으로 보입니다.

## 업데이트

- 앱 안 업데이트 파일은 별도 공개 저장소에서 받습니다. 이 저장소의 Release에는 직접 받는 통합 설치기와 SHA-256만 남깁니다([ADR 0008](../decisions/0008-update-repository.md)).
- `변경 사항 보기`는 지금처럼 이 저장소의 같은 버전 Release를 엽니다.
- 0.15.4에서 올릴 때는 바뀐 파일만 받습니다. 0.15.3은 전체 설치 파일을 받습니다.

## 소스 실행

- 소스 실행·개발·빌드에 쓰는 Python을 일반 CPython 3.14.x x64로 통일했습니다(검사 기준 3.14.8). 3.12와 3.13은 더 이상 지원하지 않습니다. 설치판 사용자에게는 영향이 없습니다.

## 첨부 파일

| 파일 | 용도 |
|---|---|
| `WatchedKettle-0.15.5-public-unsigned-setup.exe`와 `.exe.sha256` | 새 설치와 0.15.3에서의 업데이트. 직접 받을 파일은 이것입니다 |
| `WatchedKettle-0.15.5-public-<구성>-from-0.15.4.zip` | 0.15.4 앱 안 업데이트용 변경분. 체크섬은 업데이트 목록에 있습니다 |
| `WatchedKettle-0.15.5-update.json`과 `.json.sha256` | 0.15.4 앱이 읽는 업데이트 목록 |

0.15.5부터 앱 안 업데이트는 업데이트 전용 저장소의 Release를 읽습니다. 0.15.6부터 이 저장소의 Release에는 통합 설치기와 `.sha256`만 올립니다.
