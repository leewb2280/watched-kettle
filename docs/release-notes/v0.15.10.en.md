# Watched Kettle 0.15.10

[한국어](v0.15.10.md) · [English](v0.15.10.en.md)

Released 2026-10-22. Adds automatic updates, which download a new version and apply it at the next start, and lets image decorations on pet speech bubbles repeat to fit the bubble height.

**You only need `WatchedKettle-0.15.10-public-unsigned-setup.exe`.**

> Unofficial project. Not made or endorsed by, or affiliated with, OpenAI or Anthropic.

## Installing and updating

- **New installation:** download `WatchedKettle-0.15.10-public-unsigned-setup.exe` and its `.exe.sha256` attached to the Release. Compare the hash with `Get-FileHash .\WatchedKettle-0.15.10-public-unsigned-setup.exe` in PowerShell, then run it.
- **Updating from 0.15.9, 0.15.8 or 0.15.7:** click `App settings → Version & updates → Check for updates → Update`. Only the changed files are downloaded when possible.
- **Updating from 0.15.6 or 0.15.5:** the same steps download the update installer for your edition. Changed-file updates cover the previous three versions.
- **Updating from 0.15.4 or 0.15.3:** the same steps download the full installer, because those versions read this repository's Releases, and this repository carries only the combined installer.
- Your edition, tools, settings, custom pets and history are kept. The history database format is the same as 0.15.9 and is not converted. The installer is unsigned, so Windows SmartScreen may show a warning.
- Version 0.15.9 and earlier do not have the automatic updates below, so update to 0.15.10 yourself as described above. Automatic updates work from 0.15.10 to the next version onward.

## Automatic updates

- **Downloaded now, applied at the next start:** when `Check for updates automatically` finds a new version in its daily check, the app downloads the changed files in the background, verifies them and prepares the new program next to the current one. The app does not restart on its own; the pet says "A new version is downloaded" once. The new version takes over the next time the app starts (after restarting the PC, or quitting from the tray and starting it again).
- **Apply right away:** click `Restart now` in `App settings → Version & updates` to restart into the new version immediately.
- **When the installer is needed:** if the changed files alone cannot be used because your version is too old, or preparing them fails, the app does not download the large installer on its own. It tells you about the new version as before and installs when you click `Update`.
- **Turning it off:** turn off `Install updates automatically` (on by default) on the same page and the app only tells you about new versions. With `Check for updates automatically` off, automatic installs do not run either.

## Pet speech bubbles

- **Repeating decorations:** a pet package can declare that a bubble border decoration (stitches, for example) repeats to fit the body height. As the bubble grows or shrinks, more or fewer copies appear at the same size and spacing. Decorations are never stretched, and only copies that fit completely are drawn. They follow the bubble scale as before.
- Existing fixed decorations, buttons and the Customize preview are unchanged. No new settings screen is added.
- The default pet Mori Bot looks the same. Repeating decorations appear only on pets that declare them.

## Security

- The image library Pillow is upgraded from 12.3.0 to 13.0.0, which fixes eight vulnerabilities in Pillow 12.3.0 published on 2026-10-20 (out-of-bounds reads in the TIFF and GIF decoders, a decompression bomb bypass and others).
- Pet images and bubble decorations (importing, the installed pet list, loading a pet) are now opened only as PNG and WebP. Images in any other format never reach a decoder, whatever the file name. Your own images in bubble customization still accept PNG, WebP and JPEG.

## For pet package authors

- Add an optional `repeatY` to an image layer in `bubbleTheme.frame` of `pet.json`, such as `"repeatY": {"gap": 3, "bottomInset": 6}`. It repeats downward from a `top-left`, `top-center` or `top-right` anchor. `gap` is the space between copies and `bottomInset` is the margin above the bottom of the body. See the [pet package format](../pet-package-format.en.md) for details.
- Version 0.15.9 and earlier do not know `repeatY` and show the decoration once. If a package needs repetition, set its minimum app version to 0.15.10 or newer.
