# Watched Kettle 0.15.8

[한국어](v0.15.8.md) · [English](v0.15.8.en.md)

2026-10-19 공개. 0.15.7의 사용량 위젯 고정 해제, 위젯 꾸미기 미리보기, 사용량 기록 탭을 다듬은 수정판입니다.

**`WatchedKettle-0.15.8-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.8-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.8-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.7·0.15.6·0.15.5에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 가능하면 바뀐 파일만 받습니다.
- **0.15.4·0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다. 두 버전은 이 저장소의 Release를 읽고, 이 저장소에는 통합 설치기만 올리기 때문입니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 기록 DB 형식은 0.15.7과 같아 바뀌지 않습니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 고친 점

- **사용량 위젯 고정 해제:** 위젯 고정을 풀어도 위젯 내용이 다시 그려질 때까지 클릭이 뒤에 있는 창으로 통과하던 문제를 고쳤습니다. 이제 고정을 풀면 바로 위젯을 끌 수 있습니다. 고정을 켜고 끌 때 위젯이 같은 자리에서 한 번 다시 표시됩니다.
- **위젯 꾸미기 미리보기:** `꾸미기 → 위젯`에서 미리보기 아래 `지금 값`·`예시 값` 버튼과 설명 문구가 카드 테두리에 붙어 있던 여백을 고쳤습니다.
- **배경색 안내:** `배경색` 아래에 쓸 수 있는 조건(`배경 재질`이 단색이고 `색`이 배경색 직접 지정일 때)과, 색 창의 사각형에서 위아래로 밝기·좌우로 진하기를 바꾸는 방법을 안내합니다.
- **사용량 기록 탭:** `사용량 → 기록`에서 Codex와 Claude Code가 같은 출처 줄(`Codex | Claude Code`·상태 문구·`기록 지우기`)을 씁니다. 출처를 바꿔도 아래 검색줄과 목록이 움직이지 않고, 프로젝트 정렬 상자의 폭도 같습니다.
- **Codex 기록 지우기 위치:** Codex 현재 계정의 작업 기록 지우기를 `사용량 → 설정 → 데이터 관리`에서 `기록` 탭 출처 줄로 옮겼습니다. Codex를 고르고 `기록 지우기`를 누르면 지금과 같은 확인 창이 뜹니다. `데이터 관리`에는 기기 관측 기록 지우기만 남습니다.
