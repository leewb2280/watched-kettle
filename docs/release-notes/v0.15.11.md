# Watched Kettle 0.15.11

[한국어](v0.15.11.md) · [English](v0.15.11.en.md)

2026-10-30 공개. 말풍선을 직접 꾸미는 편집기와 여러 펫을 한 펫의 모습으로 묶는 펫 잇기를 더하고, 정식 출시(1.0)를 앞두고 보안·안정성·성능을 전체 점검한 버전입니다.

**`WatchedKettle-0.15.11-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.11-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.11-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.10 이하에서 업데이트:** 이번 버전은 설치 프로그램 자체가 바뀌어서, 바뀐 파일만 받는 업데이트 대신 설치 구성에 맞는 업데이트 설치 파일을 한 번 받습니다. `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누르세요.
  0.15.10의 `업데이트 자동 설치`도 이런 경우에는 큰 설치 파일을 자동으로 받지 않고 새 버전을 알리기만 합니다.
- **0.15.4·0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 기록 DB 형식은 바뀌지 않습니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 말풍선 꾸미기

- `꾸미기 → 말풍선 꾸미기`가 탭으로 정리된 편집기가 됐습니다. **배경**(단색·무늬·내 이미지), **테두리**, **모양**(모서리·꼬리·안쪽 선·후광·글 여백), **장식** 순서로 고릅니다.
- 장식은 미리보기에서 바로 눌러 고르고, 끌어서 옮기고, 크기를 바꿉니다. 기본 장식과 내 이미지를 여러 층으로 쌓을 수 있습니다.
- 내 이미지는 끌어다 놓기·붙여넣기로 넣고, 접히는 썸네일 보관함에서 다시 씁니다. 같은 그림을 다시 넣어도 복사본이 늘지 않습니다.
- 만든 디자인을 이름 붙여 저장하고, 파일로 내보내 다른 PC와 나누거나, 펫 패키지용으로 내보낼 수 있습니다.
- 여러 말풍선이 쌓일 때 장식 여백 때문에 사이가 지나치게 벌어지던 문제를 고쳤습니다.

## 펫 잇기와 외형 전환

- `펫 잇기`로 설치된 펫 여러 마리를 한 펫의 여러 모습으로 묶습니다. 모습 사이에 전환 애니메이션을 넣을 수 있고, 만든 펫을 다시 열어 고칠 수 있습니다.
- 펫 패키지의 외형 전환이 두 모습에서 여러 모습과 선택적 전환으로 넓어졌습니다. 규격은 [펫 외형](../pet-appearance.md)에 있습니다.

## 펫과 설정창

- `꾸미기 → 펫`에서 펫 애니메이션 속도를 50~200%로 조절합니다. 모든 펫에 함께 적용됩니다.
- 펫 관리에서 앞 동작 직후 바로 누른 스위치·버튼이 무시되던 문제를 고쳤습니다.
- 설정창 슬라이더 옆에 긴 설명이 있으면 값이 잘리던 문제를 고쳤습니다.
- 펫 가져오기 화면을 입력·확인·결과 단계로 정리했습니다.

## 보안과 안정성 (1.0 전 점검)

- 설정창을 Electron 44.9.3으로 올렸습니다(보안 수정 포함). 설정창 실행 파일은 다른 프로그램이 Node나 디버거로 쓸 수 없게 잠갔습니다.
- 앱과 연동 기능이 외부 프로그램(Git Bash, PowerShell, Codex 등)을 이름만으로 찾지 않고 정해진 위치에서만 실행합니다. 작업 중인 프로젝트 폴더에 같은 이름의 파일이 있어도 실행하지 않습니다.
- 한 PC를 여러 Windows 사용자가 함께 쓸 때 두 번째 사용자의 앱이 시작되지 않을 수 있던 문제를 고쳤습니다. 앱과 연동 기능이 쓰는 연결은 사용자마다 따로 만들어집니다.
- 업데이트를 받아 둔 뒤 더 새 버전을 직접 설치해도 다음 시작 때 이전 버전으로 되돌아가지 않습니다. 설치 프로그램은 새 버전을 검사한 뒤 바꿔 넣으며, 설치를 취소하거나 실패하면 기존 버전이 그대로 남습니다. 이전 버전에만 있던 파일도 설치 폴더에 남지 않습니다.
- Codex·Claude Code 설정을 바꿀 때 만드는 백업 파일은 파일마다 최근 5개만 남깁니다. 이전 버전이 남긴 백업도 설치·업데이트 때 정리합니다.
- 말풍선 이미지로 아주 큰 그림을 넣으면 거부합니다. 말풍선 디자인 파일의 검사도 강화했습니다.

## 성능

- Codex·Claude Code가 도구를 쓸 때마다 실행되는 연동 프로그램이 더 빨리 끝납니다(이 PC 측정 p95 104 → 85ms).
- 아무 작업이 없을 때 Codex 기록 확인과 계정 확인에 쓰던 CPU와 백그라운드 프로세스를 줄였습니다.

## 펫 패키지를 만드는 분께

- 외형 전환 v2(여러 모습, 선택적 전환)와 말풍선 장식 층을 쓸 수 있습니다. [펫 패키지 형식](../pet-package-format.md)과 [펫 외형](../pet-appearance.md)을 참고하세요.
- 말풍선 꾸미기의 `펫 패키지용으로 내보내기`로 만든 장식을 패키지에 넣을 수 있습니다.
