# Watched Kettle 0.15.7

2026-10-19 공개. 펫 더블클릭 동작과 설정창 홈, Claude Code 열기, 펫·위젯 고정(클릭 통과)과 전역 단축키, 펫 가져오기 확장(ZIP·폴더·설치 명령어·Codex 설치 목록), 펫 관리 화면 정리, 설정창 정보 메뉴와 알림 기록, Codex 작업 상태와 사용량 기록 개선을 담았습니다.

**`WatchedKettle-0.15.7-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.7-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.7-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.6·0.15.5에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 가능하면 바뀐 파일만 받습니다.
- **0.15.4·0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다. 두 버전은 이 저장소의 Release를 읽고, 이 저장소에는 통합 설치기만 올리기 때문입니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.
- 펫+비서 구성의 기록 DB는 처음 실행할 때 새 형식(스키마 v9, Codex 사용량 프로젝트 분류 추가)으로 한 번 바뀌며, 바꾸기 전에 같은 폴더에 백업(`.bak`)을 만듭니다. 0.15.7을 실행한 뒤 0.15.6 이하로 되돌리면 이전 버전이 새 DB를 열지 않아 비서 기록이 보이지 않습니다. 펫 기능은 그대로 동작합니다.

## 펫 더블클릭과 설정창 홈

- 펫을 더블클릭하면 손 흔들기와 함께 **설정창 홈**이 열립니다. 이전 버전의 "Codex 열기" 고정 동작 대신 이것이 기본값이 됩니다.
- `꾸미기 → 펫 → 동작·화면 → 더블클릭 동작`에서 `설정창 홈`, `Codex 열기`, `Claude Code 열기 (VS Code)`, `손 흔들기만` 중에서 고를 수 있습니다. 모든 선택에서 손 흔들기는 그대로입니다.
- `Codex 열기`와 `Claude Code 열기 (VS Code)`는 새 대화를 만들지 않고 가장 앞에 있던 Codex 또는 VS Code 창을 복원·활성화합니다. 창이 없으면 앱을 시작하고, 실패하면 설정창 홈과 오류 안내를 보여 줍니다.
- 펫만 설치 구성에서도 설정창에 홈이 생겨 펫·말풍선·앱 설정으로 바로 갈 수 있습니다.

## 펫·위젯 고정

- 펫이나 사용량 위젯이 다른 앱을 가릴 때 **고정**하면 클릭이 뒤에 있는 창으로 통과합니다. 펫과 위젯은 따로 고정합니다.
- 고정은 펫 우클릭 메뉴, 트레이 메뉴, 설정창에서 켜고, 트레이 메뉴·설정창·단축키로 풉니다.
- `펫 고정 단축키`·`위젯 고정 단축키`에 원하는 조합(Ctrl이나 Alt와 문자·숫자·F1–F24)을 지정하면 어느 앱을 쓰든 눌러서 고정을 켜고 끌 수 있습니다. 처음에는 지정돼 있지 않고, 두 단축키에 같은 조합은 쓸 수 없습니다.
- 펫+비서 구성에서는 `고정할 때 버튼 말풍선도 통과`를 고를 수 있습니다. 기본값은 꺼짐이라 말풍선 버튼은 계속 누를 수 있습니다.
- 고정해도 펫은 보이고 움직이며 마우스를 쳐다봅니다. 자세한 사용법은 [사용자 가이드](../user-guide.md#펫위젯-고정)를 참고하세요.

## 설정창 알림 기록

- 설정창의 `활동 기록`이 **`알림 기록`**으로 바뀌었습니다. 말풍선으로 지나간 알림과 이번 실행의 작업 이벤트를 다시 보는 곳입니다. 알림 설정은 지금처럼 `말풍선`·`사용량` 화면에 있습니다.
- `확인하지 않은 알림`은 5건이 넘으면 `더 보기`로 펼치고, `모두 확인`으로 한 번에 확인 처리할 수 있습니다. 기다리던 알림 말풍선도 함께 내려갑니다.
- `최근 활동`을 `알림`·`확인 필요`(권한 요청·확인 필요·실패)·`상태 변화`·`완료`로 나눠 볼 수 있습니다.
- 작업별 토큰 기록은 `사용량`에서만 보여 줘, 같은 작업이 두 줄로 나오지 않습니다. 진행 중인 대화는 `홈`에서 모두 보여 줍니다.

## 펫 관리

- 펫 관리 창의 `선택` 버튼을 목록 위 `순서 편집` 옆으로 옮겼습니다. 휴지통에서는 개수·크기 요약 오른쪽에 있습니다. 선택 모드에서는 같은 자리에 `현재 화면 전체 선택`과 `선택 취소`가 나타납니다.
- `선택`은 직접 추가한 펫(사용자 펫 폴더의 펫)이 목록에 있을 때만 누를 수 있습니다. 기본 제공 펫은 지우지 않고 숨기기만 할 수 있습니다.

## 펫 가져오기

- `꾸미기 → 펫 → 펫 가져오기`가 세 가지 입력을 받습니다. **파일·폴더**는 PNG/WebP에 더해 펫 ZIP과 `pet.json`이 있는 펫 폴더를, **설치 명령어**는 CodexPetDB·Pets Codex에서 복사한 설치 명령을, **Codex에 설치된 펫**은 Codex 사용자 폴더의 펫을 받습니다.
- 설치 명령어는 실행하지 않습니다. 펫 ID만 읽어 해당 서비스에서 직접 받으므로 Node.js나 별도 CLI가 필요 없습니다. 이 기능은 **다운로드**를 누를 때만 인터넷에 연결하며, 계정이나 사용 기록은 보내지 않습니다.
- 이름·설명·제작자·크기·바라보기·자동 행동·말풍선 장식 같은 지원 정보를 함께 가져옵니다. 가져오지 않는 정보(이 앱이 쓰지 않는 항목, 다른 설치 환경의 장식을 가리키는 말풍선 설정)는 등록 전에 알려 줍니다.
- 가져오기 창에서 9개 동작(V2 펫은 방향 자세까지)을 미리 볼 수 있습니다. 추가만 해서는 지금 쓰는 펫이 바뀌지 않습니다.

## 정보 메뉴

- 설정창 왼쪽 메뉴에 `정보`가 생겼습니다. 버전과 설치 구성, 이번 버전의 새로운 기능, 앱에 포함된 오픈소스 구성 요소의 라이선스를 볼 수 있습니다.
- 전체 패치노트·변경 이력(모든 버전의 Release 목록)·GitHub 저장소·버그 제보·라이선스 링크는 기본 브라우저로 열립니다. `라이선스 폴더 열기`는 각 라이선스 전문이 있는 설치 폴더의 `licenses` 폴더를 엽니다.
- 업데이트한 뒤 처음 실행하면 펫이 "업데이트를 마쳤어요"라고 한 번 알려 줍니다. 말풍선이 꺼져 있거나 쉬는 중이면 보이지 않고, 나중에 다시 보여 주지 않습니다.

## 설정창과 메뉴 다듬기

- 트레이 메뉴를 `알림 잠시 쉬기`·`펫 숨기기`·`펫 고정`·`위젯 고정` 묶음과 `홈 열기`·`사용량 보기`·`설정`·`업데이트 확인` 묶음으로 나눴습니다. 펫만 구성의 트레이 `펫 설정`은 `설정`으로 이름을 맞췄습니다.
- 트레이의 `업데이트 확인`을 누르면 `앱 설정`의 버전 줄을 열면서 바로 확인을 시작합니다.
- 같은 동작은 한 이름으로 부릅니다: `화면 가운데로 불러오기`, `펫 옆으로 되돌리기`. 펫 우클릭 메뉴의 `혼자 행동하기`·`화면 안에서 걷기`·`항상 위에 표시`도 설정창과 맞췄고, 이동 디스플레이 옆 버튼은 `선택한 디스플레이로 옮기기`가 됐습니다.
- 단축키를 지정하지 않은 칸은 버튼처럼 보이지 않게 흐린 글자로 바꿨습니다. `알림 기록`의 이미 확인한 항목은 `확인함`으로 표시합니다.
- 펫+비서 홈의 부제를 홈에 모인 내용에 맞추고, 펫만 구성 왼쪽 메뉴의 `꾸미기` 간격을 고쳤습니다. 다 번역된 공식 언어팩에는 번역 개수를 보이지 않습니다.
- `더블클릭 동작`을 `앱 설정`에서 펫 화면의 `동작·화면` 탭(마우스 반응 거리 아래)으로 옮겼습니다.
- 설정 이름을 누르면 옆의 스위치가 켜지고 꺼집니다. `알림 기록`·`연결·진단`의 정보(i) 아이콘은 Tab 키로 가서 설명을 볼 수 있고, 화면 읽기 프로그램이 Codex 연결 상태 점과 설정 설명을 함께 읽습니다.

## 고친 점

- Codex 작업이 App Server 저장 기록상 끝난 것으로 판정된 뒤에도 같은 작업에서 새 도구 호출이 이어지면, 카드와 작업 개수에서 빠진 채 남던 문제를 고쳤습니다. 이제 다시 작업 중으로 표시합니다. 프로젝트 카드의 작업 중 개수에는 권한 처리 중인 작업도 셉니다.
- Codex 사용량 기록의 프로젝트 분류를 저장해 두어, 앱을 다시 켜도 기존 분류를 바로 보여 주고 바뀐 대화만 다시 확인합니다. 프로젝트명·대화 제목은 계속 실행 중 메모리에만 보관합니다.
- Claude Code 사용량 기록에서 대화 도중 작업 폴더(워크트리 등)를 옮기면 같은 대화가 `Claude Code 작업`이나 폴더 이름의 별도 프로젝트로 나뉘던 문제를 고쳤습니다. 이미 저장된 기록도 대화를 시작한 프로젝트로 합쳐 보여 줍니다.
