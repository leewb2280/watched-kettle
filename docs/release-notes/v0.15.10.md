# Watched Kettle 0.15.10

[한국어](v0.15.10.md) · [English](v0.15.10.en.md)

2026-10-21 공개. 펫 말풍선의 이미지 장식이 말풍선 높이에 맞춰 반복될 수 있게 한 버전입니다.

**`WatchedKettle-0.15.10-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.10-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.10-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.9·0.15.8·0.15.7에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 가능하면 바뀐 파일만 받습니다.
- **0.15.6·0.15.5에서 업데이트:** 같은 방법으로 설치 구성에 맞는 업데이트 설치 파일을 받습니다. 바뀐 파일만 받는 업데이트는 직전 세 버전까지 지원합니다.
- **0.15.4·0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다. 두 버전은 이 저장소의 Release를 읽고, 이 저장소에는 통합 설치기만 올리기 때문입니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 기록 DB 형식은 0.15.9와 같아 바뀌지 않습니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 펫 말풍선

- **반복 장식:** 펫 패키지가 말풍선 테두리 장식(예: 바느질 땀)을 본문 높이에 맞춰 반복하도록 선언할 수 있습니다. 말풍선이 길어지거나 짧아지면 같은 크기·간격의 장식이 늘거나 줄며, 늘어나지 않고 완전히 들어가는 장식만 그립니다. 말풍선 배율도 그대로 따릅니다.
- 기존 고정 장식과 단추, 꾸미기 미리보기는 그대로입니다. 별도 설정 화면은 추가하지 않았습니다.
- 기본 펫 Mori Bot의 모양은 바뀌지 않습니다. 반복 장식은 이를 선언한 펫에만 보입니다.

## 펫 패키지를 만드는 분께

- `pet.json`의 `bubbleTheme.frame` 이미지 층에 `"repeatY": {"gap": 3, "bottomInset": 6}`처럼 선택적 `repeatY`를 추가합니다. `top-left`·`top-center`·`top-right` 앵커에서 아래로 반복하며, `gap`은 이미지 사이 간격, `bottomInset`은 본문 하단 여백입니다. 자세한 규격은 [펫 패키지 형식](../pet-package-format.md)에 있습니다.
- 0.15.9 이하에서는 `repeatY`를 모르기 때문에 장식이 한 개만 보입니다. 반복이 꼭 필요한 패키지는 최소 앱 버전을 0.15.10 이상으로 정하세요.
