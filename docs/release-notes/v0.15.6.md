# Watched Kettle 0.15.6

2026-10-18 공개. 앱 화면 영어 지원과 사용자 언어팩, 사용량 위젯 모양 이름과 간단형 작업 상태 점, Codex 내부 임시 세션 숨김을 담았습니다.

**`WatchedKettle-0.15.6-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.6-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.6-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.5에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 바뀐 파일만 받습니다.
- **0.15.4·0.15.3에서 업데이트:** 같은 방법으로 전체 설치 파일을 받습니다. 두 버전은 이 저장소의 Release를 읽는데, 0.15.6부터 이 저장소에는 통합 설치기만 올리기 때문입니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 언어

- 앱 화면이 한국어와 영어를 지원합니다. `앱 설정 → 언어`에서 고른 뒤 언어 카드 버튼 줄 오른쪽의 `앱 다시 시작`을 누르면 선택한 언어로 앱 설정이 다시 열립니다. 처음에는 설치할 때 고른 언어를 따릅니다.
- 직접 만든 JSON 언어팩을 설치·선택할 수 있고, `언어팩 다시 읽기`로 새 팩을 찾습니다. 사용자 팩에서 빠지거나 잘못된 문구는 같은 언어의 공식 팩, 없으면 영어, 마지막으로 한국어로 채워 보여 줍니다.
- `편집용 팩으로 복사`를 누르면 현재 언어의 전체 문구로 새 사용자 팩을 만들고 선택합니다. 함께 만드는 `reference.json`에 한국어 원문·공식 영어·현재 문구·표시되는 화면이 담겨 있어 번역할 때 참고할 수 있습니다. 잘못 고친 항목은 설정창에 키와 사유를 보여 줍니다.
- 숫자에 따라 달라지는 복수형, 문구 속 변수, 앱 버전과의 호환성을 검사합니다. 자세한 방법은 [언어팩 안내](../language-packs.md)를 참고하세요.

## 사용량 위젯

- 위젯 모양 이름을 `링 / Rings`, `막대 / Bars`, `간단형 / Compact`으로 정리했습니다(이전 이름 `두 줄 막대`, `작은 칩`).
- 간단형에서도 Codex·Claude Code의 작업 상태를 같은 위치의 상태 점으로 보여 줍니다. 표시할 작업이 없으면 회색 계열, 작업 중이면 작업 색, 확인이 필요하면 확인 색입니다. 마우스를 올리면 개수를 보여 주며, 한도 정보가 없어도 작업 상태를 확인할 수 있습니다.
- `작업 상태 표시`를 끄면 상태 점과 상태 문구를 함께 숨깁니다.

## Codex 활동 표시

- Codex가 내부적으로 잠깐 만드는 임시 세션이 작업 카드·완료 알림·펫의 작업 중 표시에 나타나던 문제를 고쳤습니다.
- 사용자가 연 대화인지 확인되기 전에는 카드·완료·펫 효과를 보류합니다. 세션 로그나 Codex App Server 조회(읽기 전용)로 사용자 대화임이 확인되면 그때 표시하며, 이미 지난 시작·완료 애니메이션은 다시 재생하지 않습니다.
- 확인을 기다리는 동안 끝난 작업의 완료는 최대 5분 동안 보관했다가, 사용자 대화로 확인되면 처음 끝난 시각 기준으로 한 번만 표시합니다.
