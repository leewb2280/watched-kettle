# Watched Kettle 0.15.4

2026-10-17 공개. 펫 관리와 휴지통, 도구별 사용 스위치, 부분 업데이트와 새 버전 알림, Windows 연결 명령 수정을 담았습니다.

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.4-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.4-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.3에서 업데이트:** `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누릅니다. 기존 버전은 부분 업데이트를 지원하지 않아 이번에는 전체 설치 파일을 받습니다. 0.15.4 이후에는 조건이 맞을 때 변경분만 받습니다.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 펫 관리와 휴지통

- `꾸미기 → 펫 → 펫 관리`에서 펫을 추가하고 이름 검색·표시/숨김 필터·현재 펫 확인·순서 편집을 한곳에서 합니다. 순서는 드래그와 키보드용 이동 버튼으로 바꿉니다.
- 사용자 펫은 앱 전용 휴지통으로 옮겼다가 복원할 수 있습니다. 이동 직후 실행 취소도 제공합니다. 기본 제공 펫과 외부 경로의 펫은 숨길 수 있으며 삭제하지 않습니다.
- 현재 사용 중인 펫을 옮길 때는 대신 사용할 펫을 먼저 고릅니다. 복원하면 이전 표시 여부와 가능한 순서를 되찾으며 현재 펫을 자동으로 바꾸지 않습니다.
- 다중 선택으로 이동·복원·영구 삭제할 수 있고 진행률과 항목별 실패를 확인합니다. 중단하면 완료한 항목은 유지하고 남은 항목만 멈춥니다. 선택은 현재 검색·필터·페이지 범위에 적용됩니다.
- 휴지통은 자동으로 비우지 않습니다. 영구 삭제와 비우기는 확인 후 패키지와 해당 펫의 개별 설정을 지우며 복구할 수 없습니다. Windows 휴지통과 별도입니다.
- 파일 잠금·복원 충돌·중단된 작업은 기록을 보존해 복구하거나 다시 시도합니다. 원래 가져온 PNG/WebP 파일은 변경하지 않습니다.

## 도구마다 사용 스위치 하나

- `연결·진단`의 **Codex 사용**·**Claude Code 사용**이 각 도구의 작업 상태 연결과 사용량 수집을 함께 켜고 끕니다. 적용 전에 바뀌는 내용을 보여 줍니다.
- 끈 도구의 활동·사용량 파일 읽기를 중지하고 홈·사용량·기록·트레이·위젯에서 숨깁니다. 저장된 기록은 남아 다시 켜면 볼 수 있습니다.
- hook이 막혀 있어도 사용 스위치는 켤 수 있으며 활동 표시가 제한된다는 안내를 보여 줍니다. 사용량 화면에 있던 별도 스위치는 제거했습니다.

## 업데이트 개선

- 가능한 경우 바뀐 파일만 받아 새 프로그램을 준비한 뒤 실행기가 교체합니다. 사용할 수 없거나 준비에 실패하면 해당 구성용 설치 파일로 전환합니다.
- 받을 크기를 업데이트 줄에 표시하고, 통합 설치기는 고르지 않은 구성의 압축을 풀지 않습니다.
- 설치판은 하루에 한 번 새 버전을 확인하고 버전마다 한 번 펫 말풍선으로 알립니다. 트레이에도 `새 버전 받기`를 표시합니다. 내려받기와 설치는 직접 요청할 때 진행합니다.
- `업데이트 자동 확인`은 기본 켜짐이며 앱 설정에서 끌 수 있습니다. 말풍선 끄기·일시 중지·펫 숨김 중에는 말풍선 안내를 건너뜁니다.

## 고친 것과 이전 시 주의점

- Windows에서 Codex 관리 hook이 PowerShell로 실행될 때 경로 해석 오류로 실패하던 문제를 고쳤습니다. PowerShell·cmd 모두에서 경로와 입력을 그대로 전달합니다.
- Git Bash가 없는 Windows에서 Claude Code 관리 hook·status line이 실패하던 문제를 고쳤습니다. hook은 셸을 거치지 않는 형식으로 등록하며 Claude Code 2.1.139 이상이 필요합니다.
- 이미 연결해 둔 설치는 업데이트 후 `연결·진단`에서 해당 도구의 `복구`를 누르면 새 형식으로 바뀝니다.
- Codex만 골랐는데 Claude Code가 표시되고 대화 기록을 읽던 문제를 고쳤습니다. 기존 설치는 첫 실행 때 이 앱의 Claude Code hook·status line을 기준으로 사용 여부를 한 번 정리합니다.
- Claude Code 사용을 끄면 앱이 관리하던 status line도 되돌립니다. 무인 새 설치는 `/CLAUDECODE=on` 없이 Claude Code를 연결하지 않습니다.
- 설치기의 다음·이전 이동 때 페이지 내용이 잠깐 겹치던 문제를 고쳤습니다.
- 많은 펫의 이미지 목록을 연속 조회할 때 설정창 연결이 끊기던 문제를 고쳤습니다.
- hook과 사용량을 따로 켜고 끌 수 없습니다. 예전에 Claude Code 사용량만 켰다면 업데이트 후 `연결·진단`에서 다시 켜야 할 수 있습니다. Codex가 꺼져 있으면 펫 더블클릭은 손 흔들기만 합니다.
- 자동 확인은 GitHub에 버전을 조회합니다. 계정·기기 식별자·사용 기록은 보내지 않습니다. 부분 업데이트는 설치 폴더 옆에 준비 폴더를 사용하며 변경되지 않은 파일은 가능한 경우 하드링크로 재사용합니다.

## 알려진 제한

- 앱 UI는 한국어이며 설치·제거 화면은 한국어와 English를 지원합니다. 코드 서명이 없습니다.
- 펫만 구성의 실제 부분 업데이트, 공식 Release를 통한 0.15.4 설치와 구성 전환 등 남은 실환경 검증은 [배포 준비 상태](../../RELEASE_READINESS.md)에 기록합니다.
- 과거 개발 후보에서 측정한 업데이트 크기·속도는 이번 최종 후보의 보장값으로 사용하지 않습니다.

|---|---|
| `WatchedKettle-0.15.4-public-unsigned-setup.exe`와 `.exe.sha256` | 새 설치와 0.15.3에서의 업데이트 |
| `WatchedKettle-0.15.4-public-<구성>-update-unsigned-setup.exe`와 `.exe.sha256` | 앱 안 업데이트용 구성별 설치 파일 |
