# Watched Kettle 0.15.12

[한국어](v0.15.12.md) · [English](v0.15.12.en.md)

This version uses less memory day to day and lets the usage widget show the time a limit resets.

**You only need `WatchedKettle-0.15.12-public-unsigned-setup.exe`.**

> This is an unofficial project. It is not made or endorsed by OpenAI or Anthropic and has no affiliation with either company.

## Install and update

- **New install:** Download `WatchedKettle-0.15.12-public-unsigned-setup.exe` and its `.exe.sha256` from the Release. Compare the hash with `Get-FileHash .\WatchedKettle-0.15.12-public-unsigned-setup.exe` in PowerShell, then run it.
- **Updating from 0.15.11:** The installer has not changed, so only the changed files are downloaded. With `Install updates automatically` on, they download in the background and apply the next time the app starts. To apply them right away, use `Restart now` in `App settings → Version & updates`. The initial 0.15.11 from before the 2026-11-01 correction downloads the update installer once instead.
- **Updating from 0.15.10 or earlier:** The installer changed in 0.15.11, so the app downloads the update installer for your setup once. Use `App settings → Version & updates → Check for updates → Update`.
- Your chosen setup, tools, settings, your own pets and history are kept. The history database format is unchanged. The installer is unsigned, so Windows SmartScreen may warn you.

## Usage widget

- `Customize → Widget` has a new `Reset display` setting. `Time left` (default) shows `Resets in 4h 12m` as before, and `Reset time` shows `Resets 12:39 PM`. A reset on another day adds the date, as in `Resets Thu 11/6 9:00 AM`.
- The same setting applies to the reset time in Codex and Claude Code limit alerts.
- Reset times use the current Windows time zone. This also fixes Codex limit alerts that could be an hour off on a daylight saving change.
- Claude Code limits arrive only while you use Claude Code in a terminal, so old values no longer carry text such as `Sample from 8h ago`. Old values still turn gray.
- While Codex is working, limits are checked every minute, and once more 5 seconds after a task finishes or fails. The widget and limit alerts now catch up within seconds of a finished task instead of up to several minutes later. The regular 5-minute refresh is unchanged.

## Memory use

- Pet frames are kept compressed and unpacked only when drawn. For the default pet, the memory they take dropped from about 15 MB to about 9 MB.
- Usage, conversation details and task status now share one Codex connection process (`codex.exe`). Before, two or three ran while you used Codex.
- When there are no conversation details to look up, that connection closes after a minute and reopens when needed.
- Turning off the usage widget now closes the widget window instead of hiding it, which frees its memory.
- The short-lived `codex.exe` used to check your Codex account now starts every 30 minutes instead of every 5 (when your sign-in is stored in the `auth.json` file). Switching accounts or signing out changes that file, so the app still notices within seconds.
- With these changes, the total memory of the pet + assistant setup while idle dropped from about 180 MB to about 146 MB (measured on the development PC, including the `codex.exe` the app starts).

## Settings window

- `App settings → Performance` has a new `Settings window hardware acceleration` setting (on by default). Turning it off saves about 120 MB while the settings window is open, but transitions and blur effects may be less smooth. It takes effect when you close and reopen the settings window.
- A closed settings window now frees its memory after one minute instead of five. Reopening it then takes about half a second.
- Reopening the settings window shows the tab you last viewed while the app has been running.

## Pet window

- If the pet or the usage widget ends up below other windows, it now comes back on top within 5 seconds (previously up to a minute). To avoid fighting the Start menu or other always-on-top apps, windows covered by those are still checked only once a minute.
