# Watched Kettle 0.15.8

[한국어](v0.15.8.md) · [English](v0.15.8.en.md)

Released 2026-10-19. A fix release for 0.15.7 that polishes unlocking the usage widget, the widget preview in Customize and the usage History tab.

**You only need `WatchedKettle-0.15.8-public-unsigned-setup.exe`.**

> Unofficial project. Not made or endorsed by, or affiliated with, OpenAI or Anthropic.

## Installing and updating

- **New installation:** download `WatchedKettle-0.15.8-public-unsigned-setup.exe` and its `.exe.sha256` attached to the Release. Compare the hash with `Get-FileHash .\WatchedKettle-0.15.8-public-unsigned-setup.exe` in PowerShell, then run it.
- **Updating from 0.15.7, 0.15.6 or 0.15.5:** click `App settings → Version & updates → Check for updates → Update`. Only the changed files are downloaded when possible.
- **Updating from 0.15.4 or 0.15.3:** the same steps download the full installer, because those versions read this repository's Releases, and this repository carries only the combined installer.
- Your edition, tools, settings, custom pets and history are kept. The history database format is the same as 0.15.7 and is not converted. The installer is unsigned, so Windows SmartScreen may show a warning.

## Fixes

- **Unlocking the usage widget:** fixed clicks still passing through to the window behind after the widget lock was turned off, until the widget's contents were redrawn. You can now drag the widget right after unlocking it. The widget is shown again once in the same place when the lock is turned on or off.
- **Widget preview in Customize:** in `Customize → Widget`, the `Live values` and `Sample values` buttons and the description below the preview no longer touch the card border.
- **Background color guidance:** `Background color` now explains when it can be used (`Background material` is Solid and `Color` is Custom background color), and how to change brightness (up and down) and intensity (left and right) in the color window's square.
- **Usage History tab:** in `Usage → History`, Codex and Claude Code share the same source row (`Codex | Claude Code`, a status line and `Clear history`). Switching sources no longer moves the search row and lists below, and the project sort box keeps the same width.
- **Where Codex history is cleared:** clearing the current Codex account's task history moved from `Usage → Settings → Data management` to the source row of the `History` tab. Choose Codex and click `Clear history` to get the same confirmation as before. `Data management` now only clears device observations.
