# Watched Kettle 0.15.12

[한국어](v0.15.12.md) · [English](v0.15.12.en.md)

평소 쓰는 메모리를 줄이고, 사용량 위젯에서 한도 갱신을 시각으로도 볼 수 있게 한 버전입니다.

**`WatchedKettle-0.15.12-public-unsigned-setup.exe` 하나만 받으면 됩니다.**

> 비공식 프로젝트입니다. OpenAI 또는 Anthropic이 만들거나 승인한 제품이 아니며 두 회사와 관계가 없습니다.

## 설치와 업데이트

- **새 설치:** Release에 첨부한 `WatchedKettle-0.15.12-public-unsigned-setup.exe`와 `.exe.sha256`을 받습니다. PowerShell에서 `Get-FileHash .\WatchedKettle-0.15.12-public-unsigned-setup.exe`로 해시를 비교한 뒤 실행합니다.
- **0.15.11에서 업데이트:** 설치 프로그램은 바뀌지 않았으므로 바뀐 파일만 받습니다. `업데이트 자동 설치`가 켜져 있으면 백그라운드로 받아 두었다가 다음에 앱을 켤 때 적용합니다. 바로 적용하려면 `앱 설정 → 버전과 업데이트`의 `지금 재시작`을 누릅니다. 2026-11-01 교정 전의 초기 0.15.11은 업데이트 설치 파일을 한 번 받습니다.
- **0.15.10 이하에서 업데이트:** 0.15.11에서 설치 프로그램이 바뀌었으므로, 설치 구성에 맞는 업데이트 설치 파일을 한 번 받습니다. `앱 설정 → 버전과 업데이트 → 업데이트 확인 → 업데이트`를 누르세요.
- 고른 설치 구성과 도구·설정·사용자 펫·기록은 유지합니다. 기록 DB 형식은 바뀌지 않습니다. 설치 파일은 미서명이며 Windows SmartScreen 경고가 나올 수 있습니다.

## 사용량 위젯

- `꾸미기 → 위젯`에 `갱신 표시`를 더했습니다. `남은 시간`(기본)은 지금처럼 `4시간 12분 뒤 갱신`으로, `갱신 시각`은 `오후 12:39 갱신`으로 보여 줍니다. 오늘이 아니면 `11/6(목) 오전 9:00 갱신`처럼 날짜를 붙입니다.
- 같은 설정이 Codex·Claude Code 한도 알림의 초기화 시각 문구에도 적용됩니다.
- 갱신 시각은 Windows의 현재 시간대로 계산합니다. Codex 한도 알림이 서머타임 전환일에 한 시간 어긋날 수 있던 문제도 고쳤습니다.
- Claude Code 한도는 터미널에서 Claude Code를 쓸 때만 새로 들어오므로, 오래된 값에 `8시간 전 표본` 같은 문구를 더 붙이지 않습니다. 오래된 값이 회색으로 바뀌는 것은 그대로입니다.
- Codex 작업 중에는 1분마다, 작업이 끝나거나 실패하면 5초 뒤 한도를 한 번 더 확인합니다. 작업을 마친 뒤 위젯과 한도 알림이 최대 몇 분 늦게 맞춰지던 것이 몇 초 안으로 줄었습니다. 평소 5분 갱신은 그대로입니다.

## 메모리 사용량

- 펫 그림을 압축해 두고 화면에 그릴 때만 풉니다. 기본 펫 기준 펫 그림이 차지하던 메모리가 약 15MB에서 약 9MB로 줄었습니다.
- 사용량·대화 정보·작업 상태가 Codex 연결 프로세스(`codex.exe`) 하나를 함께 씁니다. 전에는 Codex를 쓰는 동안 두세 개가 떠 있었습니다.
- 대화 정보를 확인할 대상이 없으면 1분 뒤 그 연결을 닫고, 필요할 때 다시 엽니다.
- 사용량 위젯을 끄면 위젯 창을 숨기지 않고 닫아 메모리를 돌려줍니다.
- Codex 계정 확인용으로 잠깐 띄우는 `codex.exe`를 5분이 아니라 30분마다 띄웁니다(로그인 정보가 `auth.json` 파일에 있을 때). 계정을 바꾸거나 로그아웃하면 그 파일이 바뀌므로 지금처럼 몇 초 안에 알아챕니다.
- 위 변경으로, 펫+비서 구성을 켜 두고 아무 작업도 하지 않을 때의 전체 메모리가 약 180MB에서 약 146MB로 줄었습니다(개발 PC 측정, 앱이 띄운 `codex.exe` 포함).

## 설정창

- `앱 설정 → 성능`에 `설정창 하드웨어 가속`(기본 켬)을 더했습니다. 끄면 설정창을 연 동안 쓰는 메모리가 약 120MB 줄어듭니다. 대신 화면 전환과 흐림 효과가 덜 부드러울 수 있습니다. 설정창을 닫았다 다시 열면 적용됩니다.
- 닫은 설정창은 5분이 아니라 1분 뒤에 메모리에서 내려갑니다. 다시 열 때는 약 0.5초가 걸립니다.
- 설정창을 다시 열면, 앱을 켜 둔 동안 마지막으로 보던 탭이 그대로 열립니다.

## 펫 창

- 펫과 사용량 위젯이 다른 창 아래로 내려가면 이제 5초 안에 다시 위로 올라옵니다(전에는 최대 1분). 시작 메뉴나 다른 "항상 위" 앱 창과는 다투지 않도록 지금처럼 1분마다만 확인합니다.
