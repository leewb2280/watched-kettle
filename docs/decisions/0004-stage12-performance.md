# ADR 0004: 12단계 성능 측정에 따른 Python 유지와 부분 개선

- 상태: 승인·구현 완료 — 2026-10-02 1차 측정으로 결정, 같은 날 개선 후 재측정에서 모든 목표 통과
- 근거: 12단계 측정 계획과 2차 측정 결과(개선 후, 2026-10-02). 아래 수치는 그 결과에서 옮겼다.

## 결정

1. **앱 본체는 Python·PySide6를 유지한다.** 시작(T2 0.51/0.65초), 유휴 메모리(T3 61.4/77.7 MiB), 60분 동안의 Python 본체 메모리(+0.4 MiB 이하)가
   목표 안에 있다. 크기(T7)는 대부분 Electron이 차지해 Python 교체로 줄일 여지가 없다.
2. **설정창 숨김 상주(T4·T6)는 Python 안에서 고친다.** 숨긴 지 5분이 지나면 Electron 자식 프로세스를 종료하고 다음 열기에서 새로 실행한다.
   새로 실행해도 첫 열기가 약 0.5초라 T5(1.5초)를 지킨다. 숨김 중 메모리는 유휴 수준으로 돌아갈 것으로 예상한다. 언어 교체가 아니다.
3. **hook 브리지(T1)는 Python 경량 실행 파일을 먼저 시도한다.** bridge를 PySide6 없는 별도 실행 파일로 분리하고 import를 줄인 뒤 같은 조건으로
   다시 측정한다. p95가 100ms 이하이면 Python을 유지한다. 넘으면 네이티브 bridge 교체로 넘어가 후보 언어를 비교한다.
4. **Electron 언어 팩은 한국어·영어만 포함한다.** hook 실행 파일(약 1.75MB)을 더하자 펫+비서 ZIP이 214.2MiB로 T7(212.6MiB)을 넘었다.
   앱 UI는 한국어 전용이고 Chromium은 다른 시스템 언어에서 en-US로 돌아가므로 나머지 53개(약 48MiB)를 뺀다. 재측정 뒤 사용자 승인으로 추가했다.

## 이유

- 판정 규칙: 목표 안이면 유지, 설계 문제는 Python 안에서 고치고, 언어를 바꿔야만 목표에 들어올 때만 교체한다.
- T4·T6의 원인은 숨김 중 Electron 상주라는 정책 문제다.
- T1은 PySide6 런타임 hook과 import가 약 100ms를 차지한다. 이를 뺀 시제품이 p95 100.8ms로 경계에 있어, 언어 교체가 필요한지는 아직 판단할 수 없다.

## 결과

- **설정창:** 숨김 5분 뒤 Electron을 종료한다. 숨김 5분 뒤 트리 합계 63.2/82.1MiB, 다시 열기 451/477ms, 60분 열기·숨기기 증가 0.8/0.0MiB.
- **hook:** 펫+비서 구성에 `CodexPetsHookBridge.exe`를 추가했다. PySide6·PIL만 뺀 상태는 p95 100.1ms로 여전히 경계였고,
  `inspect`·`dataclasses`까지 빼 PyInstaller의 inspect 런타임 hook을 없애자 p95 82.9ms(수신자 없음 82.5ms)가 됐다. **Python을 유지하고 네이티브 교체는 하지 않는다.**
- **크기:** 언어 팩 정리 뒤 번들 458.3/462.3MiB, ZIP 199.2/202.2MiB.

## 위험과 후속

- hook 여유는 빈 PyInstaller 실행 파일(약 75ms) 위에서 약 17ms다. 더 느린 PC에서는 목표를 넘을 수 있으므로 15단계 실환경에서 다시 본다.
  넘으면 네이티브 bridge를 다시 검토한다. 툴체인·CI·서명 대상·hook 이벤트 정규화의 두 언어 계약 검사가 늘어나는 비용은 그대로다.
- bridge에 `inspect`·`dataclasses`를 import하는 코드가 들어가면 빌드 경계 검사(`scripts/check_edition_modules.py --edition hook-bridge`)가 실패한다.
- 이전 버전에서 등록한 hook은 앱 실행 파일 경로를 가리켜 연동 화면에서 "경로 변경"으로 보인다. 예전 `--codex-hook-bridge` 경로는 계속 동작하며,
  복구하면 새 실행 파일로 바뀐다. 13단계 Claude Code hook도 같은 실행 파일을 쓴다.
- 숨김 5분 뒤 다시 열기는 Electron을 새로 시작해 약 0.5초가 걸린다. 14단계에서 비서 센터를 Electron으로 통합하면 열기 빈도가 늘어나므로 같은 측정으로 다시 확인한다.
