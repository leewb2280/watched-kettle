# ADR 0002: 단일 비서 센터 사용

- 상태: 승인
- 결정: 설정과 진단 화면은 `ApplicationRuntime`이 소유하는 단일 비서 센터로 제공한다.
- 이유: 펫마다 설정창과 트레이를 소유할 때 생기는 중복 상태와 수명주기 문제를 제거한다.
- 결과: 독립 설정창, 구 트레이와 `managed_runtime` 호환 분기를 단계적으로 제거한다.
- 후속(2026-10-03): 11단계부터 단일 비서 센터는 `ApplicationRuntime`이 소유하는 Electron 설정창이다. 14단계에서 Qt 비서 센터와 펫만 Qt 설정창을 제거한다.
