# 지원 범위

펫+비서 구성이 어떤 도구와 실행 환경에서 무엇을 보여 주는지 정리합니다.
현재 소스 버전은 **0.15.4(베타)**입니다. 아래 검증 이력은 과거 실측과 자동 검사의 범위를 나타내며,
현재 공개 설치판의 모든 조합을 검증했다는 뜻은 아닙니다.
Claude Code 실측 자료의 기준은 2026-10-04, 당시 앱 버전 0.14.0입니다.

| 도구 | 문서 |
|---|---|
| Codex | [이 문서의 Codex 안내](#codex) |
| Claude Code | [Claude Code 지원 범위](support-claude-code.md) |

## 확인 수준

- **실측**: 실제 도구를 실행해 관측했다. 조사 기록이나 사용자 확인이 있다.
- **자동 검사**: 합성 이벤트와 회귀 테스트로만 확인했다. 실제 화면·도구로는 아직 확인하지 않았다.
- **미확인**: 코드상 예상 동작만 있고 관측한 적이 없다.

## 공통

- 설치 지원 환경은 Windows 10 이상 64비트다. 소스 실행은 Python 3.12~3.14를 지원한다.
- 도구는 별도로 설치·로그인해야 한다. 설치·제거 화면은 한국어와 English를 지원하며 앱 화면은 한국어다.
- **펫만** 구성은 Codex·Claude Code와 연결하지 않는다. 도구별 문서는 모두 **펫+비서** 구성에 해당한다.
- 연결이 실패하면 그 기능만 꺼지고 펫과 다른 도구의 표시는 계속된다(fail-open, [ADR 0003](decisions/0003-fail-open-integrations.md)).
- 프롬프트·응답·명령·경로·도구 출력은 저장하거나 로그에 남기지 않는다([개인정보와 저장소](privacy-and-storage.md)).
- 대화 탐색·작업 대기열·자동 실행은 소스에는 있지만 어떤 구성에서도 노출하거나 시작하지 않는다.

## Codex

Codex Windows 앱의 작업 상태·대화 제목·프로젝트 관계와 사용량을 표시합니다.
작업 상태는 lifecycle hook을 우선 사용하고, 필요한 경우 로컬 세션 로그의 상태 메타 이벤트를 읽기 전용으로 관찰합니다.
사용량은 로컬 Codex App Server에 요청합니다. 이 앱이 권한 요청을 대신 승인하거나 작업을 자동 실행하지는 않습니다.

| 기능 | 동작과 확인 범위 |
| --- | --- |
| 작업 상태·프로젝트 말풍선 | 작업 중·확인 필요·완료·실패를 표시. 세부 규칙은 [프로젝트 말풍선](user-guide.md#프로젝트-말풍선) 참고 |
| 제목 클릭 | Codex 앱에서 해당 대화 열기. 2026-09-05 검수본에서 Codex Windows x64 26.901.5003.0으로 실측함. 현재 공개 설치판·다른 버전 전체의 보장은 아님 |
| 이동 실패·미검증 버전 | `Codex 열기` 또는 연결 안내로 대체. Codex 홈만 열린 경우 정확한 대화 이동으로 처리하지 않음 |
| 남은 한도·초기화 시각 | 로컬 App Server가 반환한 현재 계정의 한도 표시. 도구 설치·로그인·응답 상태에 따라 제한될 수 있음 |
| 토큰·작업 기록 | 서버 계정 통계와 이 기기 로그 관측의 범위를 구분. 확인할 수 없는 작업별 수치는 측정 불가로 표시하며 임의 추정하지 않음 |

처음 연결할 때는 펫 우클릭 → `설정 → 연결·진단`에서 `Codex 사용`을 확인하고 `연결 점검`을 누르세요.
변경 내용을 검토한 뒤 적용하며 신뢰 승인 안내가 있으면 따릅니다.
절차는 [첫 연결 확인](user-guide.md#첫-연결-확인), 측정 범위는 [사용량](user-guide.md#사용량),
구현 참고는 [Codex 연동](codex-integration.md)에 있습니다. 구현 문서의 대화 조회·자동 실행 설명은 공개 기능 목록이 아닙니다.

현재 공개 설치판의 지원 도구 버전 범위와 Windows 환경별 동작은 추가 실환경 검수가 필요합니다.
과거 제목 이동 실측이나 자동 검사 결과만으로 최신 도구 버전·설치판 검증을 대신하지 않습니다.

## 두 도구를 함께 쓸 때

- Codex와 Claude Code를 둘 다 쓸 때만 말풍선·알림·트레이에 출처 색 점(Codex 남색, Claude Code 주황)을 붙인다. 기준은 Claude Code 연결과 Codex 계정 확인이다. 설정창 홈·활동 기록은 늘 출처 이름을 표시한다.
- 같은 폴더라도 말풍선 카드는 출처별로 따로 둔다.
- 사용량 수집은 도구마다 따로 켜고 끈다. 둘 다 끄면 사용량 위젯을 숨긴다.
- 두 도구의 실제 동시 사용은 자동 검사로만 확인했다(설치판 실환경 검수 예정).
